# Horizontal policy
This document describes overall horizontal policies. Policies applies to the baseline Standard Operating Environment, as such, they have a potential to be disruptive.
When new policy items are added all agents needs to re-assess if their technical subsystem requires any changes.

## Attention
Adding policies here has a risk of breaking forward compatibility for your Standard Operating Environment, as such, only make additions here if you really know what you are doing.

## Policy architecture
When new policy is added it is important to be conservative and trying and preserve the current baseline configuration state as much as possible. Meanwhile, policies listed here needs to always apply.
As an example, if there is a policy for 2048 bit encryption to be used, this needs to be the default configuration state - if applicable.

# Policy items
